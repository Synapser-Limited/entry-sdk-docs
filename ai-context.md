# AI Integration Context

Ready-to-use files for AI coding assistants (GitHub Copilot, Cursor, etc.) to integrate Entry correctly without hallucination.

Drop the relevant instructions file into your AI assistant's context window before starting an integration. Each file gives the AI the essential facts it needs: what Entry is, how to install and configure the SDK, the correct integration sequence, and the mistakes to avoid.

| File | Use for |
|---|---|
| [Web Instructions File](web-instructions-file/) | Integrating Entry into a React / web app |
| [iOS Instructions File](ios-instructions-file/) | Integrating Entry into an iOS (Swift) app |
| [Android Instructions File](android-instructions-file/) | Integrating Entry into an Android (Kotlin) app |
| [Prompt Library](prompt-library/) | Copy-paste prompts that produce a correct integration |
| [Integration Checklist](integration-checklist/) | Verify an integration is correct before going live |
